# Device Settings Audio Port — Specifications

## Requirements

| Req ID | Test Scope |
|:-------|:--------------------------------------|
| `VTS‑DSAUDIO‑001` | SHALL successfully initialize the Device Settings Audio Port sub-system, successfully terminate it, support re-initialization after a prior termination, and return a valid, non-null audio port handle for each supported port type and index with repeated requests returning an equal handle. |
| `VTS‑DSAUDIO‑002` | SHALL retrieve the current audio stream format of a valid audio port reporting a valid format value, and enable and disable each supported audio port with the reported enable state matching the state that was set. |
| `VTS‑DSAUDIO‑003` | SHALL preserve data integrity across the core audio controls — audio compression level, audio gain, audio volume level, audio delay, mute/unmute, fader control balance in the range [-32, +32], audio input mixer levels, stereo mode, stereo auto mode, and AC4 primary/secondary language codes — with each reported value matching the value that was set. |
| `VTS‑DSAUDIO‑004` | SHALL preserve data integrity across the advanced and capability-conditional audio-processing controls — dialog enhancement, Dolby volume mode, intelligent equalizer, volume leveller, bass enhancer, surround decoder, DRC mode, surround virtualizer, MI steering, graphic equalizer, loudness equivalence, and associated audio mixing — with each reported value matching the value that was set, and reporting an operation-not-supported error where the feature is not supported by the DUT. |
| `VTS‑DSAUDIO‑005` | SHALL retrieve the list of supported MS12 audio profiles, retrieve the currently active MS12 audio profile, and set an MS12 audio profile for valid profile names on supported ports, reporting an operation-not-supported error where MS12 audio profiles are not supported by the DUT. |
| `VTS‑DSAUDIO‑006` | SHALL configure the Dolby ATMOS output mode of a supported audio port and retrieve the ATMOS capability of the connected sink device reporting a valid capability value. |
| `VTS‑DSAUDIO‑007` | SHALL retrieve the audio and MS12 capabilities of each audio port matching the values declared in the device profile, and report MS11 and MS12 multistream decode support matching the corresponding fields in the device profile. |
| `VTS‑DSAUDIO‑008` | SHALL retrieve the supported ARC types and configure SAD data for HDMI ARC-type ports, enable and disable ARC/eARC audio routing, report the audio output port connection status, and register event callbacks for connection changes, audio format updates, and ATMOS capability changes, reporting an operation-not-supported error where a feature is not supported by the DUT. |
| `VTS‑DSAUDIO‑009` | SHALL report an already-initialized error on repeated initialization, a not-initialized error for operations invoked before initialization or after termination, and an invalid-parameter error for invalid or null port handles, NULL output pointers, or out-of-range parameter values. |
